Single-Pump Quad-Valve is a configuration for the OpenPump project that enables automated fluid control for up to four independent zones using a single pump. Powered by an ESP32 microcontroller and based on ESPHome and the programming language YAML, the system monitors multiple soil-moisture sensors and directs water through electronically controlled valves. When a zone is detected as too dry, the pump is activated and water is routed only to the corresponding valve. Each zone operates with its own adjustable dryness threshold and a built-in cooldown period to prevent overwatering. In addition, the system features a Telegram bot–based notification service that sends real-time messages when pumping starts and stops, allowing users to remotely monitor system activity. Designed for DIY plant watering and small-scale automation projects, this setup provides an efficient, sensor-driven, open-source solution for precise multi-zone fluid distribution.
